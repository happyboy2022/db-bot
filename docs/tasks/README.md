## 快速开始指南

### 首次开发

1. 从 T-001 开始，完成 Monorepo 初始化
2. 然后 T-002、T-003、T-004 可以并行开发
3. 查看各阶段文档了解详细任务内容

### 选择任务

1. 查看任务状态，选择 `[ ]` 未开始的任务
2. 检查依赖项是否已完成（标记为 `[x]`）
3. 优先选择 P0 任务

### 更新进度

完成任务后：
1. 在对应阶段文档中将任务状态改为 `[x]`
2. 更新本文件的进度总览表
3. 提交代码
